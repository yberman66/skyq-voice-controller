# Talking to the TV

1\. Say **“Hey Siri, Sky”** 2. Wait for it to listen 3. Say a word below

In the kitchen, say **“Hey Siri, Kitchen”** instead

**Turning on and off**

|                                      |                                  |
|--------------------------------------|----------------------------------|
| **Power on / Turn on**               | Turns the TV and the Sky box on  |
| **Power off / Turn off / Shut down** | Turns the TV and the Sky box off |

**Volume**

|                      |                                                                         |
|----------------------|-------------------------------------------------------------------------|
| **Volume up / down** | A little louder or quieter. Add a number to repeat it, like Volume up 3 |
| **Mute / Unmute**    | Switches the sound off and on again                                     |
| **Volume 20**        | Sets the sound to that number. Say any number up to 60, like Volume 25  |

**Changing channel**

|                       |                                             |
|-----------------------|---------------------------------------------|
| **Channel up / down** | Next channel up or down                     |
| **A number, 0 to 9**  | Types a channel number, one digit at a time |

**Watching**

|                           |                                |
|---------------------------|--------------------------------|
| **Play / Pause / Stop**   | Controls what you are watching |
| **Rewind / Fast forward** | Go back or skip ahead          |
| **Record**                | Records the programme          |

**Finding your way around**

|                               |                                                                                             |
|-------------------------------|---------------------------------------------------------------------------------------------|
| **Home**                      | Goes to the Sky home screen                                                                 |
| **Apps**                      | Jumps down to the Apps row (Netflix, iPlayer and so on)                                     |
| **Netflix**                   | Gets you close to Netflix. Then say Left or Right until it is highlighted, then Select      |
| **TV guide**                  | Shows what is on                                                                            |
| **Up / Down / Left / Right**  | Moves the highlight around the screen. Scroll up and Scroll down do the same as Up and Down |
| **Left 3, Down 5, and so on** | Moves that many steps in one go. Say a direction and a number from 1 to 10                  |
| **Select**                    | Chooses whatever is highlighted                                                             |
| **Back**                      | Goes back one screen                                                                        |

**Handy tips**

- In apps like Netflix, say Left or Right first so something is highlighted, then say Select.

- Apps and Netflix take about 10 seconds, and counted moves like “Down 5” take a moment. Wait for them to finish before saying anything else, and do not say them twice.

- If it does not understand, say it again clearly. Other people talking nearby can confuse it.

- When the phone rings, the TV goes quiet and pauses. After the call, say Play to carry on.
